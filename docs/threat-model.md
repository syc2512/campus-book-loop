# 威胁模型

> 范围：本仓库的单机演示部署（FastAPI + Next.js + PostgreSQL + 本地图片卷）。不是完整渗透测试报告，也不覆盖真实资金清算。

## 假设与边界

- 用户通过 HTTPS 访问 Caddy，API 不直接暴露公网；
- 认证使用 HMAC 签名 Bearer 令牌，令牌保存在浏览器 localStorage；
- 支付、退款为沙箱状态，不产生真实资金流；
- 管理员账号为演示账号，生产环境应接入正式身份体系；
- 单机部署，无 WAF、无集中日志、无专业风控；
- 不处理真实学生身份、教务数据和支付凭据。

## 资产

教材与发布数据、订单与审计记录、用户密码哈希、签名密钥、上传图片、数据库备份、演示账号可用性。

## 角色

匿名访客、学生（买家/卖家）、管理员、外部扫描者、恶意上传者、被泄露令牌的持有者。

## 威胁与控制

| 威胁 | 场景 | 现有控制 | 缺口与优先级 |
| --- | --- | --- | --- |
| 越权读取订单 | 修改订单 ID 读取他人订单 | 订单列表只返回买家/卖家本人；支付、完成、取消均校验归属 | 订单详情接口不存在，暂无 IDOR 面；新增接口时必须复用归属检查（高） |
| 管理员越权 | 学生调用审核、退款或指标接口 | `require_role("admin")`；接口测试覆盖 403 | 管理员账号无二次认证（中） |
| 令牌伪造/过期 | 篡改 payload 或使用过期令牌 | HMAC-SHA256 校验、过期时间、用户存在性检查；生产启动拒绝默认或少于 32 字符的密钥 | 无密钥轮换与多版本校验（中） |
| 令牌泄露 | XSS 或共享设备读取 localStorage | 令牌有效期 240 分钟；退出时清除；API 返回 `no-store` | 无 CSP、无刷新令牌轮换、无设备管理（中） |
| 登录暴力破解 | 批量尝试密码 | scrypt 哈希；同一邮箱+来源连续失败 5 次后限制 5 分钟；成功登录清零 | 限流只在单进程内生效，无验证码、锁定或告警（中） |
| 订单重复提交 | 网络重试或脚本重复下单 | 幂等键唯一约束；重复键返回同一订单；listing 状态改为 reserved | 幂等键由客户端生成，需限制长度和归属（已做归属校验） |
| 并发超卖 | 两名买家同时下单同一 listing | `uq_orders_active_listing` 部分唯一索引只允许一个 `pending_payment`/`paid` 订单；listing 状态检查 | 部分索引已在 SQLite 验证，PostgreSQL 实例尚未实测；应用层状态检查与插入不在同一事务锁内（中） |
| 取消/退款滥用 | 反复下单取消占用库存；管理员退款后重复购买 | 取消仅限 `pending_payment`；退款仅限 `paid` 且写审计；取消/退款后可重新下单 | 无频率限制、无风控评分；反复占用库存仍可能（中） |
| 价格与品相欺诈 | 虚报品相、标价接近新书价 | 标价不得超过新书价 90%；估价展示区间和因素 | 品相无图片复核，卖家可虚报（中） |
| 恶意上传 | 上传脚本、超大文件、伪造扩展名 | 魔数校验、类型白名单、5 MB 限制、随机文件名、SVG 不接受 | 无病毒扫描、无 EXIF 清除、无内容审核（中） |
| 路径遍历 | 通过文件名访问任意路径 | 不使用客户端文件名，服务端生成 UUID | 静态目录只暴露 uploads，风险较低（低） |
| 存储型 XSS | 书况说明或教材字段注入脚本 | React 默认转义；未使用 `dangerouslySetInnerHTML` | 图片元数据未清洗；未来富文本需白名单（中） |
| CSRF | 跨站伪造操作 | 认证使用 Authorization 头而非 Cookie，浏览器不会自动附带 | localStorage 令牌仍可被 XSS 窃取（中） |
| 枚举与爬取 | 遍历教材、发布和图片 URL | 列表分页上限 100；图片名为 UUID | 无速率限制、无防盗链、无 robots 策略（中） |
| 日志注入/泄露 | 伪造请求 ID 或日志含敏感信息 | 请求 ID 字符集与长度校验；日志只记录方法、路径、状态、耗时 | 无集中日志脱敏管道（中） |
| 依赖与供应链 | 恶意或高危依赖、镜像被替换 | 使用锁文件与固定基础镜像；CI 安装依赖 | 无依赖审计、镜像扫描与 SBOM（中） |
| 密钥管理 | `.env` 或镜像泄露密钥 | `.env*` 和密钥文件被 gitignore；生产要求显式设置 | 演示默认密钥可能被误用；需启动时拒绝弱密钥（高） |
| 拒绝服务 | 大量请求或大文件上传 | 上传大小限制；数据库连接池 | 无 WAF、限流、队列和熔断（中） |
| 数据删除 | 用户要求删除发布和图片 | 演示可通过重置卷清除 | 无自助删除、无备份删除传播（中） |

## 已实现的安全测试

- 未登录访问订单与上传接口返回 401；
- 学生访问管理员接口返回 403；
- 管理员可以列出全部状态书籍和订单，并完成下架、恢复、退款；
- 登录连续失败 5 次后返回 429；
- 生产环境弱密钥启动校验拒绝；
- API 返回 `nosniff`、`DENY`、`no-referrer` 和 `no-store` 响应头；
- 订单幂等重复提交返回同一订单；
- 取消后重新下单、退款后重新下单成功；
- 同一 listing 的第二个非终态订单被部分唯一索引拒绝；
- 非法状态迁移返回 409；
- 非图片文件上传返回 415；
- 请求 ID 生成、透传与非法值拒绝。

## 上线前优先事项

1. 分布式登录与管理员限流、验证码；强随机密钥校验已实现；
2. 令牌存储与 CSP，增加安全响应头；
3. 图片恶意内容扫描、EXIF 清除与人工审核；
4. 集中日志、告警、依赖与镜像扫描；
5. 正式身份体系、管理员二次认证和审计导出。

订单非终态唯一约束已改为部分唯一索引，并在 SQLite 上验证升级、降级和数据保留；PostgreSQL 实例仍需在部署环境实测。
