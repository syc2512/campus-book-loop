| 项目 | 内容 |

## 预期用途

模型用于辅助卖家设定二手教材价格，并向管理员提示异常估价。最终成交价仍由交易双方确认，模型输出不构成价格承诺。

## 不应使用的场景

- 替代人工鉴定正版、盗版或交易合规性；
- 对珍本、收藏书、签名本等高价值非标准商品自动定价；
- 对未在训练分布中的语种、教材类型或校园场景直接给出确定价格；
- 用于信贷、贫困生资格、保险、招聘等与学生购书无关的决策；
- 在缺少人工复核的情况下批量自动成交；
- 将本合成实验的 MAE、MAPE 或 R² 作为真实市场效果对外宣传。

## 输入

| 字段 | 类型 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| 新书价格 | 数值 | 是 | 同一 ISBN 的可靠参考价格 |
| 品相等级 | 枚举 1—10 | 是 | 使用项目统一品相标准 |
| 版次与版本匹配 | 布尔 | 是 | 当前教学使用版本或旧版 |
| 笔记与划线情况 | 布尔 | 是 | 合成实验中只区分有/无 |
| 教材类别 | 分类 | 是 | 公共课、专业课、考研资料、笔记/真题、通识读物 |
| 需求热度 | 数值 0.6—1.6 | 是 | 浏览、收藏和求购的聚合特征 |

禁止使用成交完成后产生的字段作为输入，包括最终成交价、交易结果、退款结果和买家确认信息。

## 输出

| 输出 | 说明 |
| --- | --- |
| 建议售价 | 新书价 × 预测价格比例的中心值 |
| 价格区间 | 中心价的 ±10%，上限不超过新书价的 90% |
| 主要影响因素 | 品相、类别、需求、笔记、版次、规则比例和模型比例 |
| 置信提示 | 当前仅返回固定免责声明；区间覆盖率与分布外提示尚未实现 |

## 可解释性

- 向用户展示价格区间而不是单一“准确价格”；
- 返回规则比例、模型比例和各因素系数；
- 超出售价合理区间时要求卖家备注；
- 页面固定标注“合成模型试算”，避免误解为真实市场估价；
- 人工复核和调整记录尚未实现。

## 限制与风险

- 训练数据完全合成，不能证明真实市场效果；
- 合成噪声、类别分布和价格区间由脚本设定，真实教材的版本、专业和季节差异未被建模；
- 模型预测的是价格比例，新书价格本身的质量决定结果上限；
- 教材版本变化会使历史价格快速失效；
- 教材图片无法可靠判断盗版或全部瑕疵；
- 模型更新后必须保留版本和回滚能力；
- 当前 API 在模型文件缺失时会自动回退到规则基线，但缺少线上监控与告警。
