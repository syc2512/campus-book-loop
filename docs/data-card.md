## 估价数据字段

| 字段 | 类型 | 说明 | 是否进入模型 |
| --- | --- | --- | --- |
| 新书价格 | 数值 | 同一 ISBN 的参考价 | 是 |
| 品相等级 | 1—10 | 统一品相标准 | 是 |
| 教材类别 | 分类 | 公共课、专业课等 | 是 |
| 需求热度 | 0.6—1.6 | 浏览、收藏、求购聚合 | 是 |
| 笔记情况 | 布尔 | 有/无笔记或划线 | 是 |
| 版次匹配 | 布尔 | 当前版本或旧版 | 是 |
| 发布时间 | 日期 | 仅用于时间切分 | 否（切分键） |
| 成交价、退款、买家确认 | 交易后字段 | 禁止作为输入 | 禁止 |

合成标签为“观测价格比例 = 规则比例 + N(0, 0.028)”，并截断到 [0.08, 0.86]。真实数据接入后，标签必须定义为成交价与新书价之比，且排除退款和异常订单。

## 时间切分

- 估价：按合成发布时间排序，以日期为边界切分，训练集截至 2026-06-12，验证集从 2026-06-13 开始；训练和验证不共享同一天。
- 推荐：按每位用户的交互顺序留出最后一次交互作为测试，其余作为历史；这是逐用户 leave-last-out，不是全局时间切分。
- 合成数据没有真实的季节、版本更替、曝光和成交漂移，因此时间切分只验证管线，不证明未来效果。
- 真实数据必须按全局时间切分，并去重同一用户的重复曝光、防止同一 ISBN 跨集合泄漏。

## 质量与隐私检查

- 合成生成器与评估脚本均固定随机种子，输出可逐字节复现；
- 种子账号、姓名、邮箱均为虚构，不含学号、身份证、联系方式或家庭经济信息；
- 书籍图片当前为本地卷存储，未做 EXIF 清除、人脸模糊或票据遮挡，公开前需人工检查；
- 真实数据接入前需完成字段最小化、脱敏、访问控制和删除流程，详见[隐私说明](privacy.md)。
