# 隐私与数据说明

> 状态：面向演示环境的数据边界说明。不是法律意见，也不替代上线前需要的隐私影响评估。

## 适用范围

本仓库是校园二手教材循环的参考实现，默认只使用虚构账号、手工种子数据和合成交互数据。它不连接真实教务系统，不处理真实学生身份、家庭经济情况或真实支付账户。

## 数据分类

| 类别 | 示例 | 来源 | 用途 | 公开仓库 |
| --- | --- | --- | --- | --- |
| 演示账号 | `student@campus.local`、显示名“林同学” | 手工种子 | 登录与角色演示 | 可以 |
| 教材元数据 | 书名、ISBN、作者、出版社、版次、课程编码 | 公开书目信息或手工整理 | 检索与课程匹配 | 可以，需保留来源 |
| 发布内容 | 品相、价格、书况说明 | 演示用户生成 | 交易展示 | 可以，需去除个人信息 |
| 书籍图片 | 封面、书脊、瑕疵照片 | 演示用户上传 | 展示与后续品相识别 | 需检查人脸、票据、笔记中的个人信息 |
| 订单与审计 | 金额、状态、操作记录、幂等键 | 演示流程生成 | 订单闭环与审计 | 可以，不含真实支付信息 |
| 日志 | 请求 ID、方法、路径、状态码、耗时 | 运行时生成 | 排障与可观测性 | 不提交日志文件 |

## 明确不收集

- 真实姓名、学号、身份证号、手机号、宿舍地址；
- 家庭经济情况、贫困生资格材料；
- 真实教务系统账号、课程表或成绩；
- 支付账户、银行卡、身份证照片；
- 未经授权抓取的电商、知网或社交平台数据。

生产环境如需收集联系方式，必须单独评估最小化字段、保存期限、访问权限和删除机制，不能直接复用演示设计。当前数据清单、字段、真实/合成比例和授权记录见[数据卡片](data-card.md)。

## 日志与请求 ID

每个请求返回 `X-Request-ID`，服务端记录请求 ID、HTTP 方法、路径（不含查询串）、状态码和耗时。以下内容不记录：

- 密码、令牌、Authorization 头；
- 请求体中的书况说明、图片内容；
- 完整联系方式、身份证或支付凭据。

客户端传入的请求 ID 只接受 8—64 位字母、数字、点、下划线和连字符，避免日志注入。当前日志输出到标准输出，没有集中采集、轮转和访问控制，生产环境需补齐。

## 图片与上传

- 只接受 JPEG、PNG、WebP，按文件魔数校验，不接受 SVG；
- 单张限制 5 MB，文件名由服务端随机生成，不使用用户文件名；
- 图片保存在 API 主机本地卷，通过 `/media` 提供，未接入对象存储或 CDN；
- 未做 EXIF 清除、人脸模糊、票据遮挡或恶意文件扫描；
- 公开演示前应人工检查图片是否包含人脸、姓名、学号、宿舍号、联系方式或试卷答案。

## 保留与删除

演示环境没有自动保留期限，数据随容器卷存在。重置方式见 [部署文档](deployment.md)：删除 PostgreSQL 与 uploads 卷后重新启动。生产环境需要明确：

- 每类数据的保存期限；
- 用户删除账号、发布和图片的流程；
- 审计日志的保留期限与访问审批；
- 备份中的删除传播方式。

## 第三方与外部服务

当前运行不依赖第三方分析、广告、支付或对象存储服务。计划中的 MinIO/S3、Redis、支付沙箱和监控服务在接入前需要补充数据处理者清单、区域和合同条款。

## 安全措施与已知缺口

已有：scrypt 密码哈希、HMAC 签名令牌与过期时间、登录失败进程内限流、生产弱密钥拒绝、角色检查、订单归属检查、上传类型与大小校验、CORS 白名单、请求 ID 日志、安全响应头和种子数据不含真实个人信息。

缺口：没有分布式登录限流和验证码、令牌存在浏览器 localStorage、没有 CSP、没有图片恶意内容扫描、没有集中日志与告警、没有正式的数据删除接口、没有隐私影响评估文档。详细威胁与优先级见 [威胁模型](threat-model.md)。
